# 🤖 Artificial Intelligence Chatbot using Java

An AI-based chatbot developed in Java using a rule-based response system and basic Natural Language Processing (NLP). The chatbot interacts with users through a GUI and provides responses based on predefined keywords and patterns.

---

## 📌 Project Overview

The Artificial Intelligence Chatbot is designed to simulate conversation between users and a virtual assistant. It uses keyword matching and NLP techniques to understand user inputs and generate appropriate responses.

This project demonstrates:

- Java GUI development using Swing
- Basic Artificial Intelligence concepts
- NLP processing techniques
- Object-Oriented Programming concepts

## ▶ How to Run

### Step 1

Clone the repository:

```bash
git clone <repository-link>
```

### Step 2

Navigate to the project folder:

```bash
cd AIChatbot
```

### Step 3

Compile all Java files:

```bash
javac *.java
```

### Step 4

Run the project:

```bash
java ChatbotGUI
```
